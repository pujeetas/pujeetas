### 🧠 Featured Project

**[DailyDeck – AI-Powered Full-Stack SaaS Platform](https://github.com/pujeetas/DailyDeck)**
🔗 [Live Demo](https://daily-deck-ten.vercel.app)

A RAG pipeline built over a personal knowledge base — notes are embedded with Cohere and stored in MongoDB Vector Search, so as you write, it surfaces relevant past notes with a link straight back to the source.

- Full CI/CD from GitHub straight to production on MongoDB Atlas, with uptime monitoring (100% availability so far)
- Containerized locally with Docker multi-stage builds so dev matches prod exactly
- Unit and integration tests with Vitest and React Testing Library covering auth and core user flows
- GitHub Issues API integration syncing external tasks into an internal Kanban workflow
